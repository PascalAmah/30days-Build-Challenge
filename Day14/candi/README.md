# Candi — Astro Landing Page

A recreation of the Candi candy-cart landing page, built with Astro.

## Run locally

```
npm install
npm run dev
```

Then open http://localhost:4321

## Build

```
npm run build
npm run preview
```

## Notes on interactions
- Benefit grid: hovering any cell zooms its illustration/text slightly inside its frame.
- Footer "candi-licious" wordmark: squishes/bounces on hover, and re-triggers on click/tap (for touch devices).
- Newsletter "Join →" button: bounces on hover.
